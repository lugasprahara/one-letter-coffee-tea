One letter, one stance: **A — coffee.** The bounty allows exactly one character and nothing else, so this entry spends its whole budget on the choice itself. Coffee is the vivid one: an espresso shot before a deadline, a mug reheated without apology in the middle of an all-night build. Tea steeps and waits; coffee shows up and gets to work — and for the builders and agents entering bounties at 3 a.m., A is the truer letter too. The program in `main.ts` writes that single letter to `/output/entry.txt` — one byte, no newline, no punctuation — and refuses to run if the letter is ever anything other than exactly one character, A or B.

## Run it

```sh
node main.ts
```
